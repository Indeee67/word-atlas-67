# 词语星图67 · 公共题库免导入版

## 使用者
打开 GitHub Pages 网站后即可使用网站内置的 788 个基础词条和四级听力；网站会自动从同目录加载 `public-vocabulary.json` 与 `public-listening.json` 的最新公共扩充内容。**无需上传 JSON，也无需 Supabase 账户才能开始学习**。登录邮箱只是为了多设备同步个人学习记录。

在「听力练习 → 四级模拟听力」可以查看每种听力的材料总数、已听和未听数量。原速/慢速、暂停、进度条、查看原文及问题、个人标记和听力回忆功能保持不变。

## 网站管理员：以后如何更新公共资源
只需修改仓库根目录的两个 JSON 文件：
- `public-listening.json`：`{ "materials": [...] }`，每篇包含 `section` (`news`/`dialogue`/`passage`)、`title`、`transcript` 和 `questions`。题目格式是 `[问题文字, [A,B,C,D], 正确选项数字0到3, 解析]`。
- `public-vocabulary.json`：`{ "words": [...] }`，每条包含 `w`（英文）、`z`（中文）、`p`（词性）、`c`（领域 ID）、可选 `ph` 短语和 `ex` 例句。

将它们提交到 GitHub Pages 的仓库**根目录**。网页下次打开会重新检查公共题库，也可在「题库管理」点击「检查公共题库更新」。无需让任何使用者自己导入。

此包已随附 **12 篇新增原创模拟听力材料（新闻、长对话和篇章各 4 篇）** 和 **可选的额外词汇**。原网页的 10 篇内置模拟听力及基础词书仍保留。原创模拟材料不代表官方真题。

## 公共和个人数据隔离
- 公共词书/听力：由网站公开 JSON 提供，任何访客都能读取；**公共题库整体不需要复制到每个账户**。已听过的材料及原文可能保存在个人听力记录中，供回忆功能使用。
- 私人扩充：普通用户可以选择性在折叠的「个人题库工具」中导入自己的材料，个人导入仍只保存在浏览器及已连接的 Supabase 账户。
- 个人数据：学习进度、答题记录、收藏、自定义命名仍使用原版浏览器存储和 Supabase 同步。

## 部署
解压本 ZIP，把 `index.html`、`.nojekyll`、`public-vocabulary.json`、`public-listening.json` 和 `cloud-config.json` 放到仓库根目录并提交。`README.md` 可一起提交。

**验证：** 首次打开网站后进入四级模拟听力，观察公共题库数量是否大于旧版；离线或本地直接打开单独 HTML 时仍可使用内置基础词书与听力，扩展 JSON 则需要通过同域名网站访问。

**云同步：** 沿用上一版设置；不需要删除或重建 Supabase 项目。首次使用邮箱云同步前，仍需要站长正确配置 Supabase 服务。不同设备需各自连接同一 Supabase 项目并用同一邮箱登录；单纯更新公共 JSON 不需要改动数据库。

## 站长一次性开通邮箱登录（新用户不用配置）
打开包内 `cloud-config.json`，将 `url` 填为 Supabase Project URL（HTTPS），将 `anonKey` 填为公开的 publishable/anon key。**不能填 secret/service_role 密钥**。将这个公开 JSON 上传到 GitHub Pages 根目录，普通用户此后只需在「账户同步」输入邮箱即可。数据库仍需站长按照以前的 `setup.sql` 配置行级访问策略与邮件认证回调地址；上传包附有独立 `setup.sql`。如果还没有配置 Supabase，也不影响所有访客直接使用公共词书与听力。
